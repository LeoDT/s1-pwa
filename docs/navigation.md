# 导航与页面框架（App 式）

> 结论：**放弃浏览器式前进/后退历史，改用固定的层级路径 + 手势返回。**
> 本文件替代 overview.md 中 D16/D17 关于导航与返回的描述。

## 1. 固定层级

```
板块列表（每个板块一个固定路径 /f/<fid>[/<page>]）
   └─ 帖子详情（/t/<tid>[/<page>][#pid<pid>]）
         返回 → 总是回到该帖子所属板块的列表（同一个页码 + 滚动位置）
```

- 没有"全局后退按钮"：顶栏不提供返回箭头。
- 返回只有两个入口：**详情页横向滑动**、系统返回键/手势（Android 硬件键、iOS 边缘手势）。
- 板块切换不是"历史"，是**替换当前列表**。
- 帖子内的翻页、引用跳楼、跨帖跳转一律 **replace**，不堆历史；所以系统返回永远只回列表。

## 2. 路由行为表

| 动作 | 路由 | 历史操作 |
|---|---|---|
| 打开帖子 | `/t/<tid>` | push（唯一一次入栈） |
| 帖子翻页 | `/t/<tid>/<page>` | replace |
| 引用跳楼 / 跨帖跳转 | `/t/<tid>/<page>#pid…` | replace |
| 返回列表（滑动/硬件键） | `/f/<fid>/<page>` | 有列表栈 → pop；否则 replace |
| 列表翻页 | `/f/<fid>/<page>` | replace |
| 切换板块 | `/f/<fid>` | replace |
| 打开板块管理 / 设置 | `/boards`、弹层 | replace（管理页返回首页） |

深链直达 `/t/...` 时没有列表栈，滑动手势会用 replace 导航到该帖所属板块，保证"总是回到列表"。

## 3. 顶栏（常驻 / 仅小屏详情页收起）

| 场景 | 顶栏 |
|---|---|
| 列表页（小屏 / 大屏） | **常驻**，作为布局中的一行（不遮挡内容） |
| 详情页（大屏） | **常驻** |
| 详情页（小屏 < 1024） | **浮层**：不占布局高度，向下滚动收起、向上或回到顶部（`scrollTop < 8`）展开 |
| 非浏览页（登录/设置/板块管理） | 常驻 |

小屏详情页为浮层时，滚动容器顶部预留 `header-h + safe-area-top`，所以停在顶部时标题可见。
顶栏左侧预留"浏览历史"入口（后续里程碑），右侧只有设置。

## 4. 列表页

- **下拉刷新**（触摸设备）：`scrollTop === 0` 时下拉，超过 56px 松手重新拉取；下拉过程有阻尼与指示文案。
- 不再有全局刷新按钮；重新聚焦窗口时列表会自动重取（`refetchOnWindowFocus`）。
- 板块条贴在**列表底部**：小屏为屏幕底部固定条，大屏为左栏（360px）底部固定条，同一个组件、同一位置语义。
- 板块条只有切换，没有"管理"入口（管理在设置里）。

## 5. 详情页

- 页码条**统一在内容区底部**（小屏与大屏一致，都贴所在栏的底部）。
- 横向滑动返回：位移 > 70px 且纵向位移 < 50px，左右方向都接受（页面内没有横向内容，避免误伤）。
- 返回时恢复列表的页码与滚动位置。

## 6. 设置入口

- 顶栏齿轮 → 设置抽屉。
- 抽屉内包含：访问令牌、账号/退出、**常用板块管理**、正文字号、省流量模式、图片缓存、关于。
